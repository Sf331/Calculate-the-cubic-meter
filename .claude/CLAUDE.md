# 课立方 · 项目约定

本项目是**演示用 demo**，不是上线系统。

## 前端界面规则（硬性）

**追求最简单、能用的界面，不做任何花哨的设计。**

- 字体统一用**宋体** `font-family: "宋体", SimSun, serif;`，全局生效，不要用无衬线字体。
- 不写自定义主题、渐变、阴影、动画、过渡效果、图标装饰。
- 不引入额外的 UI 美化库。组件一律用 Element Plus 的默认外观，不加样式覆盖。
- 页面能用表格 + 表单 + 弹窗表达就不用别的形式。
- 需要写 CSS 时只写布局必需的（宽高、间距、对齐），不写视觉样式。

**为什么**：这个 demo 是用来演示业务功能的，评委看的是数据联动，不是界面。花在界面上的每一分钟都是从业务功能上抢的。

## 其他约定

- 严格按 `编码计划书.md` 的目录结构和技术选型执行，不要自行引入计划书里没有的依赖。
- 本轮只搭框架，不写具体业务逻辑。
- 后端私有配置放 `backend/.env`，前端放 `frontend/.env`，两者都已在 `.gitignore` 中，仓库只提交 `.env.example`。
- 不做多租户、不做 Spring Security、不做审计日志、不做 Flyway —— 理由见计划书第一节。
